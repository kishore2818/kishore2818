# 📂 Featured Projects

## 🚦 KAAPAAN — AI Traffic Violation Detection System

An AI-powered traffic monitoring system that uses computer vision to detect supported traffic violations and manage evidence through a centralized dashboard.

- Detects helmet violations, mobile phone usage, triple riding, and other supported violations.
- Integrates AI inference with backend APIs and dashboard components.
- Supports violation records, evidence management, and automated alerts.

**Tech:** MERN Stack · Python · YOLOv8 · OpenCV · Cloudinary · MongoDB

---

## 🎥 SRI — AI Video Intelligence System

An AI-powered video analysis system designed to support surveillance and investigation workflows.

- Computer vision-based video analysis.
- Suspect-tracking and intelligent video-analysis workflows.
- Exploration of automated video summarization to reduce manual review time.

**Tech:** Python · PyTorch · FastAPI · MongoDB · OpenCV

---

## 🛕 SHREE — AI Crowd Monitoring Agent

An intelligent crowd-monitoring project focused on crowd-density analysis and anomaly detection.

- Computer vision for crowd monitoring.
- Exploration of unusual activity detection.
- Scalable architecture for intelligent monitoring workflows.

**Tech:** Python · AI/ML · Computer Vision · Microservices

---

## 🌹 ROSE AI — Assessment Assistant

An AI-focused project associated with assessment workflows involving Talentely and Examly.

- AI-assisted assessment preparation and workflow support.
- Potential for practice-question generation and answer explanations.
- Scope for performance analysis and personalized learning insights.

**Tech:** Python · AI/ML · Web Technologies

---

## 🌲 AUGNI GUARD — AI & IoT Forest Fire Prevention

A research-oriented project exploring early forest fire detection using intelligent sensors, drones, and Edge AI.

- Environmental monitoring using smart sensors.
- Edge AI for faster detection and reduced cloud dependency.
- Exploration of drone-assisted monitoring and intelligent alerts.
- Focus on early warning and environmental protection.

**Tech:** Edge AI · IoT · Python · Computer Vision · Smart Sensors · Drone Technology
